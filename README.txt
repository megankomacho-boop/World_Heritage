世界遺産 Webページ

1. ZIPファイルを「すべて展開」してください。
2. world-heritage フォルダ内の index.html をダブルクリックして開いてください。
3. メニューや写真カードから各世界遺産のページへ移動できます。

HTML・CSS・JavaScript・画像は同じフォルダ構成のまま使用してください。
外部フォントや外部プログラムを使っていないため、ページ本体はオフラインでも表示できます。ユネスコへのリンクはインターネット接続が必要です。

構成：トップページ＋6つの紹介ページ
写真：提供されたZIPファイルの画像8点を使用（元画像のまま）
解説参考：ユネスコ世界遺産センター。各ページに公式リンクを掲載。
